## Carpetas

| Carpeta | Contenido |
|---|---|
| `diagramas/` | Diagrama entidad-relación (general y por dominio) y de arquitectura, en Mermaid editable (`.mmd`) y en imagen |
| `evidencias/` | Capturas reales de la aplicación (`*.png`) y evidencias de cada sección del documento |
| `evidencias/pruebas/` | 35 pruebas funcionales: captura de cada caso y registro `resultados.json` |
| `evidencias/no_funcionales/` | Pruebas de rendimiento, compatibilidad, accesibilidad y seguridad (`resultados_no_funcionales.json`) |
| `evidencias/esquema/` | Exportación del esquema de la base de datos desde Supabase |
| `evidencias/admin/`, `logros/`, `indicadores/`, `dispositivos/` | Panel de administración, logros registrados, corte de indicadores M1–M7 y representaciones en Android e iOS |
| `mockups/` | Mockups en imagen y en HTML |
| `presentacion/` | Presentación de la defensa |

El código de la aplicación y su guía de instalación están en el [README principal](../README.md).
